# Airwolf brand asset

The app icon combines a nose-on helicopter, angular wolf-like canopy and amber radio waves. It is inspired by the 1980s television series and designed as an original emblem for the spectrum/packet analyzer.

- Source: `public/airwolf-mark.png` — generated bitmap, also used by the sidebar and browser favicon.
- Package icon: `build/icon.png` — the same image resized to 1024 × 1024 for platform packaging. Electron Builder produces the platform icon resources.
- Generation mode: built-in `image_gen` tool; no API/CLI fallback.
- Colors: graphite, silver-white and amber, matching the instrument-style interface.
- Wordmark: live `AIRWOLF` text in the interface, so it stays crisp and accessible.

## Generation prompt

Use case: logo-brand. Asset type: production desktop app icon for Airwolf, a radio spectrum and packet analyzer. Create a striking original emblem inspired by the 1980s Airwolf television show's sleek black helicopter and aviation mood. A single simplified, recognizable nose-on helicopter silhouette, sweeping rotor bar, sharply angular silver-white cockpit and black fuselage, with subtle wolf-ear geometry integrated into the canopy and a small warm amber radio-wave accent. Minimal bold geometric shapes, premium instrument-panel aesthetic, high contrast, readable at 32 pixels. Centered composition with generous padding on a solid very dark midnight graphite rounded-square app tile. Palette: near-black graphite, silver-white, warm amber. Flat graphic design with restrained metallic shading; no photorealism, no scenery, no mockup, no fine detail, no letters, no text, no watermark. One finished square icon.
