# Airwolf brand asset

The app icon combines a nose-on helicopter, angular wolf-like canopy and amber radio waves.

- Source: `public/airwolf-mark.png` — generated bitmap, also used by the sidebar and browser favicon.
- Package icon: `build/icon.png` — the same image resized to 1024 × 1024 for platform packaging. Electron Builder produces the platform icon resources.
- Colors: graphite, silver-white and amber, matching the instrument-style interface.
- Wordmark: live `AIRWOLF` text in the interface, so it stays crisp and accessible.
