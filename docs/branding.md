# Airwolf brand asset

The app icon combines a nose-on helicopter, angular wolf-like canopy and amber radio waves.

- Package icon: `build/icon.png` — the generated bitmap at 1024 × 1024 for platform packaging (the 1254 × 1254 original is in git history). Electron Builder produces the platform icon resources.
- Interface mark: `public/airwolf-mark.png` — the same image at 540 × 540, enough for its largest use (270 px on the startup screen at 2×); also the sidebar logo, browser favicon and window icon.
- Colors: graphite, silver-white and amber, matching the instrument-style interface.
- Wordmark: live `AIRWOLF` text in the interface, so it stays crisp and accessible.
